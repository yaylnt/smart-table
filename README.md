# Умная таблица

Интерактивная таблица продаж с полным набором функций: поиск, фильтрация, сортировка, пагинация и вывод данных, полученных с сервера.
### Посмотреть demo: [click](https://yaylnt.github.io/smart-table/)

## Мой вклад в проект

- Модульная архитектура: логика разбита на независимые модули (table, pagination, sorting, filtering, searching), каждый по единой схеме initModule(settings) → функция (data, state, action) => data.

- Конвейер обработки данных: поиск → фильтрация → сортировка → пагинация → вывод, что позволяет постепенно сужать выборку и не делать лишних вычислений.

- Работа с <template>: строки, шапка, фильтры, поиск и пагинация собираются через клонирование шаблонов и привязку элементов по data-name, без ручного поиска по DOM.

- Единый обработчик событий: change, submit и reset сведены к одному вызову onAction, с preventDefault, определением нажатой кнопки через e.submitter и отложенным вызовом при reset.

- Пагинация: расчёт числа страниц, обрезка данных через slice, вывод ограниченного числа кнопок через getPages, статус «с какой по какую строку» и обработка действий «первая», «предыдущая», «следующая», «последняя».

- Сортировка: переключение направления по кругу через карту переходов, сброс состояния остальных колонок и восстановление выбранного режима при перерисовке.

- Фильтрация: динамическое заполнение select значениями из индексов данных, очистка полей по кнопке с data-field, применение правил сравнения через createComparison и defaultRules.

- Поиск: отдельный модуль с собственным компаратором на базе searchMultipleFields, работающий сразу по нескольким полям.

- Работа с состоянием формы: значения собираются в объект, приводятся к нужным типам и используются всеми модулями единообразно.

- Отладка и проверка: тестирование с разными датасетами, проверка краевых случаев, использование DevTools и брейкпойнтов.
